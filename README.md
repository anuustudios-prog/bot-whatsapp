# Anuu WhatsApp Bot

A simple and lightweight WhatsApp Bot built with **@whiskeysockets/baileys** supporting Pairing Code authentication.

## Features
- Pairing Code Authentication (No QR Code required)
- `.alive` & `.ping` commands included
- Easy deployment on GitHub Codespaces / Local PC
